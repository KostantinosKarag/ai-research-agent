# Autonomous AI Research Agent

An autonomous Python agent that conducts web research using Wikipedia APIs and generates structured Markdown reports.

---

## Key Features
- **Automated Research:** Fetches real-time structured data and executive summaries.
- **Report Generation:** Automatically converts raw API responses into clean, ready-to-read Markdown reports (`research_report.md`).
- **Robust Error Handling:** Built with standard HTTP request handling to ensure high compatibility across environment setups.

---

## Tech Stack
- **Language:** Python 3.9+
- **API & Networking:** Requests (REST API)
- **Output Format:** Markdown
